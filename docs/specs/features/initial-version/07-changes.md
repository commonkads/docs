## Deviations from design

**`architecture.md` — `api-author` placement:** the initial draft placed `api-author` as a direct child of both `author` and `engine` in the dependency tree. Corrected to show it only under `author`, since `api-author` → `author` → `engine` is the actual dependency chain.

**`concepts.md` — knowledge layers:** the initial draft described norms, abstraction, evaluation, and selection as universal "knowledge layers" that every domain always has. These are Assessment-PSM-specific file types. Rewritten to distinguish the two universal files (`domain.yml`, `ontology/domain.yml`) from PSM-specific knowledge files, with Assessment files shown as an example only.

**`concepts.md` — auditability:** the initial draft claimed results could be "reproduced exactly" by re-running with the same document versions. Corrected to distinguish deterministic steps (reproducible) from LLM steps (not guaranteed), with the audit log providing explanation rather than replay.
